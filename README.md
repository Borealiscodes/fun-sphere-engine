✨ Overview

The Fun‑Sphere Engine is a geometric narrative runtime built on reversible operator flow,  
holonomy‑induced submanifolds, and trace‑preserving world‑state physics.

Instead of branching logic or scripted events, Fun‑Sphere treats narrative as manifold traversal:

- Story actions → reversible operators  
- Plot twists → holonomy curvature  
- Zones → invariant submanifolds  
- Factions → operator bundles  
- Monsters → spectral perturbations  
- Quests → reversible operator sequences  

This repo contains the core engine, world topology, holonomy logic, and mobile‑ready UI hooks.

---

🧠 Core Concepts

🟦 Neutral Manifold
A flat ND manifold with identity metric.  
All narrative evolution begins here.

🟧 Holonomy Loops
Closed operator sequences that return to the same point  
but transform the frame → narrative curvature.

🟩 Sovereign Submanifolds (Fun‑Spheres)
Regions where holonomy is non‑trivial.  
These become zones, biomes, story pockets, or corruption wells.

🟥 Safety Membrane
A gradient‑based firewall preventing runaway instability.  
If breached, the engine resets to equilibrium.
